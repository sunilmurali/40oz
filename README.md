## Bolt Drop Game

An exciting electromagnetic bolt-dropping game with beautiful scenery and serene music! 

### How to Play:
1. Open `game.html` in your browser
2. Click the 🔊 icon to enable serene ambient music
3. Hold the "HOLD TO SLIDE" button - the electromagnet will slide along the rope
4. Release the button at the perfect moment to drop the bolt
5. Try to land the bolt in one of the target buckets below!
6. Score points for successful hits
7. Enjoy the changing scenery each round

### Game Features:
- **Electromagnetic Physics**: Realistic bolt drop simulation with gravity
- **5 Scenic Backgrounds**: Cycle through Mountain Vista, Ocean Breeze, Sunset Dreams, Forest Serenity, and Aurora Night
- **Serene Ambient Music**: Calming procedurally-generated soundtrack using Web Audio API
- **Multiple Target Buckets**: 2-3 randomly placed buckets per round for varied gameplay
- **Dynamic Scenery**: Background changes after each round for visual variety
- **Score Tracking**: Keep track of your score, hits, and total attempts
- **Visual Feedback**: Particles and messages for hits and misses
- **Music Toggle**: Turn ambient music on/off with the 🔊/🔇 button
- **Touch Support**: Works on both desktop and mobile devices
